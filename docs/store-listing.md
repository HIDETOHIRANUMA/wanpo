## プロモーションテキスト（iOS・170字以内）

真夏のお散歩の途中に、犬と一緒に涼しい室内でひと休み。室内同伴と冷房を運営が確認したお店だけを、確認日つきで表示します。

## 説明文

```
暑い日のお出かけに、犬と一緒に入れる「涼しい室内」を探せるアプリです。

■ 暑い時間帯に、いますぐ涼める場所へ
環境省の暑さ指数（WBGT）で、これからの暑い時間帯を表示。「いますぐ涼みたい」で、徒歩で行ける開いている涼しい場所を1件、大きく出します。

■ お散歩プランと涼しさの地図
お散歩の時間を選ぶと、途中で涼める場所をつないだルートを提案。地図では、徒歩10分以内に涼める場所がある範囲を色で表示します。

■ 近い順に探せる
現在地、エリア、駅から、犬と室内で過ごせるカフェ・レストラン・休憩所を近い順に表示します。現在地はボタンを押したときだけ使い、保存や送信はしません。

■ 確認済みの情報を、ひと目で
「室内に犬と入れるか」「冷房があるか」は、運営が確認した記録をもとに表示します。確認した日も一緒に出すので、情報の古さが分かります。テラス席だけのお店は「室内で過ごせる」には含めません。

■ 「うちの子」に合うかを照合
体重・犬種（短頭種かどうか）・頭数や、カート・バッグ・リードなどの同伴方法を登録すると、お店の条件に合うかを照合します。お店の1日のタイムラインで、犬と過ごせる時間と暑い時間帯の重なりも分かります。犬の情報はこの端末にだけ保存されます。

■ うちの子カード
ワクチン接種日や性格をまとめたカードを、入店時にお店の方へ画面で見せられます。

■ いま開いているか、すぐ分かる
営業時間と、犬と過ごせる時間帯から「いま利用できるか」を表示します。

■ 犬が主役の口コミと写真
実際に行った飼い主さんの口コミや犬の写真を、「うちの子に近いサイズ・犬種」の順に見られます。不適切な投稿は通報・ブロックできます。

■ 保存して、オフラインでも確認
気になるお店は保存しておけます。電波の弱い場所でも、保存したときの情報を見られます。

※ 掲載情報は確認日時点のものです。お出かけ前に、お店へ最新の情報をご確認ください。
```

## 年齢区分

- 質問票では「ユーザー生成コンテンツ（口コミ・写真）あり」「通報・ブロック・運営による削除あり」と回答します。暴力・性的表現などはすべて「なし」。
- 投稿の通報・非表示・ブロック・利用規約の同意はアプリに実装済みです（App Store 審査ガイドライン 1.2 の要件）。

## 審査担当者へのメモ（App Review Information）

```
・ログインなしで、施設の検索・詳細・保存・犬の条件登録まで使えます。
・口コミ・写真の投稿、情報の報告、通報には、メールアドレスに届く6桁の確認コードでログインします。審査担当の方ご自身のメールアドレスでログインできます（パスワードはありません）。
・初めて口コミ・写真を投稿するときは、利用規約・投稿ガイドラインへの同意を求めます。
・各投稿の「…」から通報・投稿者のブロックができます。ブロックは「マイページ」→「アカウント」で解除できます。
・アカウント削除は「マイページ」→「アカウント」→「アカウントを削除」からアプリ内で完了します。
・位置情報は「現在地から探す」を押したときだけ使い、サーバーへ送信しません。
```
