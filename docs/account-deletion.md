# アカウント削除のご案内（雛形）

> ストアの「アカウント削除の方法」欄や公開ページに使う雛形です。**公開URL・お問い合わせ先は未設定**です。

## アプリから削除する

1. 「犬の条件」タブ →「ログイン（情報修正の報告用）」または「アカウント」を開く
2. ログイン中であることを確認し、「アカウントを削除」を押す
3. 確認画面で「削除する」を押す

削除はサーバー側で本人確認（ログイン中のトークン）をしたうえで行います。完了すると「アカウントと報告を削除しました」と表示されます。失敗した場合は「削除は完了していません」と表示されるので、通信状況を確認して再度お試しください。

## 削除されるもの

- アカウント（メールアドレスを含む認証情報）
- あなたが送った情報修正の報告と「犬と過ごせたか」の回答
- 送信回数の記録

## 削除されないもの

- 運営が確認のうえ更新した施設の掲載情報
- この端末に保存した施設・犬の条件（ログイン不要の機能のため端末内にあります。「この端末のデータを削除」またはアプリの削除で消えます）

## アプリを使えない場合

お問い合わせ先：**（未設定）** に、登録したメールアドレスから「アカウント削除希望」とご連絡ください。本人確認のうえ削除します。

## 技術メモ（運営向け）

- 実装：`supabase/functions/delete-account`（Edge Function）が `auth.getUser(token)` で本人を特定し、`auth.admin.deleteUser` で削除。
- `public.place_reports.reporter_id` と `private.report_quota.user_id` は `auth.users` に `on delete cascade`。
- ローカルのデータだけを消して「アカウント削除済み」と表示することはありません（`src/app/account.tsx`）。
