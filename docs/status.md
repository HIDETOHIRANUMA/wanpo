## 仕様の解釈

- **「犬が大丈夫なお店か」の投票（UGC）**：仕様の「公開口コミを含めない」「利用者の報告を公開情報へ自動反映しない」と両立させるため、投票は**運営の確認用アンケート**として実装しました。選択肢（室内で過ごせた／カート・バッグ等が必要だった／テラス席のみだった／入れなかった／わからなかった）を `place_reports` に `report_type = dog_ok_vote`、`review_status = pending` で保存します。集計や件数も含めて**公開せず、掲載条件にも自動反映しません**。不正投稿を防ぐため、報告と同じくメールOTPのログインと1日10件の上限を共有します。
- **「この範囲で検索」**：地図を動かしただけでは基準点を変えず、ボタンを押したときに地図の中心を新しい基準点（「地図の中心」と表示）にします。距離は「地図の中心から直線○km」と表示し、現在地からの距離とは表示しません。
- **エリアを選んだ場合**：そのエリアの中心付近を基準点にし、施設もそのエリアに限定します。「対象エリア全体」は3区の中心付近を基準点にします。
- **1施設1区画**：`place_dog_zones` を別テーブルにし、MVPの間だけ `place_id` を一意にしています（インデックスを外せば複数区画へ拡張可能）。
