## 1. 取得する情報と利用目的

| 情報 | いつ | どこに保存 | 目的 |
| --- | --- | --- | --- |
| 現在地 | 「現在地から探す」を押したときだけ1回 | **保存しない**（端末内で距離計算にのみ使用） | 近い順に並べる |
| 保存した施設・犬の条件（名前・体重・同伴方法・証明書）・報告の下書き | 利用者が入力・保存したとき | **端末内のみ** | 保存一覧の表示、条件の照合 |
| メールアドレス | 報告・回答・口コミ・写真の投稿・通報の前に確認コードでログインするとき | 認証サービス（Supabase Auth） | 本人確認、不正投稿の防止（**公開しません**） |
| 報告・回答の内容、対象施設、訪問日（任意）、受付日時 | 送信したとき | サーバー（Supabase） | 掲載情報の確認（公開しません） |
| 口コミ（ニックネーム、本文、選んだタグ、訪問日（任意）、投稿日時） | 投稿したとき | サーバー（Supabase） | 施設ページで**公開**します |
| 犬の写真（縮小・再エンコードした画像）と、ひとこと（任意） | 投稿したとき | サーバー（Supabase Storage・非公開の保管場所） | 施設ページで**公開**します（期限つきのURLで表示） |
| 通報（対象の投稿、理由、日時） | 通報したとき | サーバー | 不適切な投稿の非表示・確認（公開しません。投稿者に通報者は知らされません） |
| 1日の送信・投稿・通報の回数 | 送信したとき | サーバー | 投稿頻度の制限 |

バックグラウンドでの位置情報の取得、移動履歴の記録、位置情報のサーバー保存は行いません。

### 口コミ・写真について

- 口コミと写真は、投稿するとすぐ公開されます。公開されるのはニックネーム・本文・タグ・訪問日・写真・ひとことで、**メールアドレスやアカウントIDは公開しません**。
- 写真は端末で縮小してJPEGに作り直してから送ります。撮影場所などの位置情報（EXIF）は読み込まず、送信もしません。
- 写真に人の顔や個人を特定できる情報が写らないようにしてください。複数の通報があった投稿は自動で非表示になり、運営が確認のうえ削除・非表示にすることがあります。
- 自分の口コミ・写真は、施設ページからいつでも削除できます。
- 写真の閲覧には期限つきのURL（約1時間）を使い、公開中の写真と投稿者本人の写真だけが表示されます。

## 2. 外部サービスへの送信

- **地図表示**：iOS は Apple のマップ、Android は Google のマップを使用します。地図を表示するために、表示範囲や端末・アプリの情報が各提供者に送信されます。本アプリは利用者の現在地を地図提供者へ渡しません（地図上の現在地表示は使用していません）。各社のプライバシーポリシーが適用されます。
- **経路を見る**：施設の座標だけを端末の地図アプリ（Apple マップ／Google マップ）に渡します。
- **電話・公式サイト・予約ページ**：端末の電話アプリ・ブラウザで開きます。予約ページは店舗または予約サービスの提供者が管理しており、そこで入力した情報には各提供者のプライバシーポリシーが適用されます。本アプリは予約内容を受け取りません。
- **認証・データ保存**：Supabase（ホスティング地域：**（未設定）**）。確認コードのメール送信には **（未設定：SMTP事業者）** を使用します。

## 3. 第三者提供

法令に基づく場合を除き、本人の同意なく第三者に提供しません。報告・回答・通報の内容は公開しません（公開するのは、利用者が公開を前提に投稿した口コミ・写真だけです）。

## 4. ログ

アプリのログやエラー通知に、認証トークン、メールアドレス、正確な位置情報を記録しません。

## 5. 保存期間と削除

- 端末内の情報：アプリの「犬の条件」タブ →「この端末のデータを削除」、またはアプリの削除で消えます。
- アカウント：アプリの「アカウント」画面から削除できます。サーバーで本人を確認したうえで、アカウント（メールアドレス）と、あなたの報告・回答・口コミ・写真（ファイルを含む）・通報・送信回数の記録を削除します。運営が確認のうえ更新した施設の掲載情報は残ります。

掲載情報は確認日時点のものです。当日の入店、冷房の稼働、空席を保証するものではありません。
